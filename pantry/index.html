비밀 창고 동기화

GitHub의 비밀 창고(Secret Gist)에 내 식료품 재고를 숨겨서 보관해요. 한 번 연결해 두면 수량을 바꾸거나 품목을 지울 때마다 저절로 저장되고, 다른 기기에서도 그대로 이어서 쓸 수 있어요.

1

내 비밀 창고 열쇠 만들기

아래 버튼을 누르면 GitHub의 열쇠 만들기 페이지가 열려요. gist 하나만 체크된 채로 열리니, 그대로 페이지 맨 아래 Generate token만 누르면 돼요.

GitHub에서 열쇠 만들기 ↗

GitHub에 로그인되어 있어야 해요. 만든 열쇠는 그 화면에서 한 번만 보여주니 복사해 두세요.

2

열쇠 붙여넣기

복사한 열쇠를 아래에 붙여넣고 연결 및 동기화를 눌러 주세요. 위시리스트에 쓰던 열쇠를 그대로 넣으셔도 식료품 전용 비밀 창고로 따로 보관돼요.

열쇠는 이 브라우저의 이 기기에만 저장되고, GitHub 말고 다른 곳으로는 보내지 않아요. 재고는 남에게 보이지 않는 비밀 창고에 들어가요.

3

다른 기기에서도 열쇠 하나로

새 기기에서도 같은 열쇠를 붙여넣으면 내 식료품 창고를 자동으로 찾아 그대로 이어서 써요. 위시리스트 창고와는 섞이지 않아요.
